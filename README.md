Entry for the make.fun bounty "Ridiculous at First Glance, Real by the Second".
`main.py` (Python standard library only) writes a single-sentence startup pitch
to `/output/entry.txt`: a crow-powered litter-cleaning service for mall parking
lots — an idea that sounds like a joke until the customer and the money come
into focus.

Run it locally with `python3 -P -s main.py`; it writes the pitch to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
